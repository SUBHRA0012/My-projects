## OVERVIEW
Developed a fully functional Grocery E-commerce Website using HTML, CSS, JavaScript, and PHP. 
The platform allows users to browse products, add items to the cart, select quantities, and complete purchases. 
Users can view their order history and invoices in the Orders section, which includes an order progress tracking bar. 
The project also features a dedicated Admin Panel for managing users and website operations.

## Technologies used
- Frontend: HTML, CSS, Bootstrap, JavaScript
  - Bootstrap 5.3.8: https://getbootstrap.com/docs/5.3/getting-started/introduction/ 
- Backend: PHP
- Database: MySQL
- Libraries & Plugins:
  - Drift Zoom (Image Zoom Effect)
  - SweetAlert2 (Custom Alert Messages)
    - source: https://www.jsdelivr.com/package/npm/sweetalert2
    - CDN: https://cdn.jsdelivr.net/npm/sweetalert2@11
  - PHPMailer (Email Sending Functionality)
    - source: https://github.com/PHPMailer/PHPMailer

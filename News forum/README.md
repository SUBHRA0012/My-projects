News Forum

A simple PHP-based news discussion forum where users can view categories, post threads, comment on topics, and engage in healthy discussions.

Features

- Categories-wise thread listing
- Users can post threads and replies
- Basic user session management
- Auto timestamp on posts
- Pagination for threads and comments
- Contact form to reach the admin

Tech Stack

- Frontend: HTML, CSS, Bootstrap
- Backend: PHP (Vanilla PHP)
- Database: MySQL
- Server: Apache (XAMPP/WAMP)
